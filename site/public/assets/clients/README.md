## דרישות טכניות:

- **גודל מומלץ**: 400x200 פיקסלים
- **רקע**: שקוף (PNG) או לבן
- **איכות**: לוגואים חדים ובהירים

## הערות:
- התמונות יוצגו ב-grayscale (שחור-לבן)
- בעת hover - הצבע המלא יופיע
- הקרוסלה רצה אוטומטית בלולאה
- כדי להוסיף/להסיר לקוחות - ערוך את `page.tsx`
