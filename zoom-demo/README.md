# דמו: אפקט זום בגלילה

דף סטטי אחד (`index.html`) שמדגים את אפקט ה"זום" שרואים באתרים כמו של Zera Studio:
כרטיס קטן שמתרחב עד שהוא ממלא את המסך, ואחריו "מנהרה" של תמונות שמתקרבות אל הצופה.

- נבנה עם [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) (pin + scrub). אין build, פותחים את הקובץ בדפדפן.
- התמונות ב-`img/` הן גרסאות מוקטנות של התמונות מהפרויקט.
