# חיבור המערכת לגוגל שיטס · פעם אחת, 5 דקות

הגיליון יהיה מסד הנתונים של רבר: כל הלידים, היומן, התשלומים והצוות נשמרים בו,
וכל העובדים רואים את אותו מידע מכל מכשיר. חינם, בחשבון הגוגל של רבר.

## 1. גיליון חדש
1. נכנסים לחשבון הגוגל של רבר (rever.isr@gmail.com)
2. פותחים [sheets.new](https://sheets.new) ונותנים לו שם: **רבר · מערכת ניהול**

## 2. להדביק את הקוד
1. בתפריט: **תוספים ← Apps Script**
2. מוחקים את כל מה שכתוב שם
3. מדביקים את כל התוכן של הקובץ `Code.gs` ← לוחצים 💾 שמירה

## 3. התקנה
1. למעלה, ליד "הפעלה", בוחרים את הפונקציה **setup** ← **הפעלה**
2. גוגל יבקש אישור: **בדיקת ההרשאות** ← בוחרים את החשבון של רבר
   ← "Advanced / מתקדם" ← "Go to … (unsafe) / מעבר" ← **אישור**
   (זה הקוד שלכם, בגיליון שלכם. גוגל מציג את האזהרה הזו לכל סקריפט פרטי)
3. חוזרים לגיליון: נוצרו לשוניות בעברית (לידים, יומן, צוות…)

## 4. פרסום
1. ב-Apps Script: **פריסה (Deploy) ← פריסה חדשה (New deployment)**
2. ⚙️ סוג: **אפליקציית אינטרנט (Web app)**
3. **הפעלה בתור:** אני · **למי יש גישה:** כל אחד (Anyone)
4. **פריסה** ← מעתיקים את **כתובת אפליקציית האינטרנט** (מסתיימת ב-`/exec`)
5. שולחים את הכתובת לאלמוג

## אחרי זה
- נכנסים למערכת ← "הגדרה ראשונה" ← גל יוצר קוד מאסטר
- בהגדרות ← צוות והרשאות: מוסיפים את ליאל, ארד וספיר עם קודים
- בהגדרות ← גוגל שיטס: מחברים את גיליון הלידים הקיים כדי למשוך ממנו לידים

## חשוב לדעת
- **אל תשנו** שמות של לשוניות או את שורת הכותרות. אפשר לקרוא ולסנן בגיליון חופשי.
- **"כל אחד" בפריסה** = כל מי שיש לו את הכתובת יכול לדבר עם הקוד, אבל הקוד לא נותן כלום בלי קוד אישי של עובד.
  הקודים נשמרים מוצפנים, ואחרי 5 ניסיונות שגויים העובד ננעל ל-10 דקות.
- **שיתוף הגיליון עצמו:** רק גל וליאל. לעובדים לא משתפים את הגיליון, הם עובדים דרך המערכת
  (מי שיש לו גישה לגיליון רואה הכל, כולל מחירים).
- **עדכון קוד בעתיד:** מדביקים קוד חדש ← פריסה ← ניהול פריסות ← ✏️ ← גרסה חדשה ← פריסה.
  הכתובת נשארת אותה כתובת.
